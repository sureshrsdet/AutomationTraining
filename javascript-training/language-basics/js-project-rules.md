1. Project Folder Naming Convension (Root Folder)
   Convension: kebab-case (lowercase + hypen)
   ex: javascript-training-concepts

2. Sub Folder / Module Naming Convension
   Convension: kebab-case (lowercase + hypen) or CamelCase
   ex:
   src/
   page-objects/
   pageMethods (Starts with lower-case followed by uppercase char before each new word)

3. JS/TS Naming Convension
   Convension: kebab-case (lowercase + hypen)
   ex: first-program.js
